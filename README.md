## 🚀 Sobre mim

Sou **Desenvolvedor Full Stack**, cursando Engenharia de Software, com experiência prática em construir aplicações completas — do frontend ao backend — com foco em **clareza, performance e escalabilidade**.

Trabalho principalmente com **React, Node.js e TypeScript**, criando desde interfaces modernas até APIs REST bem estruturadas, com deploy em nuvem (**AWS**) e containers (**Docker**).

Curto resolver problemas de verdade, não só "fazer funcionar". Pra mim, código bom é aquele que outro dev entende sem sofrimento — e isso vale tanto pro código quanto pra forma como eu documento e explico o que construo.
